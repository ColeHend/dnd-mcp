# rules-glossary-2024.json

The SRD 5.2.1 Rules Glossary as structured JSON (174 entries). The 5e-database dataset has no 2024 rules at all
(`/api/2024/rules` is a 404), so this file is the only structured source of 2024 rules text the server has.

- **Source:** `serving-solid-characters/SolidCharacters.Repository/data/srd/2024/rules.json`
  (https://github.com/ColeHend/serving-solid-characters), commit `94b630ccaa6c41d08de27c23cd08bce523ab1076`
  (2026-08-09), generated by that repo's `scripts/srd-gen` from the SRD 5.2 markdown.
- **Copied:** 2026-09-26, byte for byte.
- **sha256:** `f64a894fd3ab99d0e3e5600a72dcbf43c30eb32716cc3b7a7e8645adbb0f776a`
- **Licence:** the text is SRD 5.2.1 material (CC-BY-4.0; statement in the README and `rules://attribution`).

Never edit it by hand. To update it, copy the new file over this one, update the hash above and in
`RulesGlossaryTests`, and srd.db rebuilds itself on next start (the file's hash is part of its staleness key).
